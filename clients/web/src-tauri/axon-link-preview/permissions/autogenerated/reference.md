## Default Permission

Build a link preview on this device and cancel one in flight (ADR 0132 § 3). The command reaches only HTTPS pages on public DNS names whose public IPv4 address it validated itself, so the grant is not a general network reach.

#### This default permission set includes the following:

- `allow-lookup`
- `allow-cancel`
