## Default Permission

Register an APNs or FCM device token, read the alerts still on screen, and post a local notification that collapses with the remote one.

#### This default permission set includes the following:

- `allow-capabilities`
- `allow-device-token`
- `allow-delivered-event-ids`
- `allow-pending-wake`
- `allow-post-local`
- `allow-register-listener`
