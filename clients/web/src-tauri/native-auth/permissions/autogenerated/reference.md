## Default Permission

Everything the shell's sign-in needs: ask what this platform supports, run Sign in with Apple, and keep Axon's own tokens in the Keychain.

#### This default permission set includes the following:

- `allow-capabilities`
- `allow-apple-sign-in`
- `allow-secret-load`
- `allow-secret-set`
- `allow-secret-delete`
