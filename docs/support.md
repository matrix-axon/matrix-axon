# Axon Support

Axon is a self-hosted Matrix client stack: the Axon server, plus the web, desktop, terminal, and mobile clients that talk to it.
This page lists the ways to get help, in the order we suggest trying them.

## Chat with us on Matrix

Join the support room for quick questions and help from the community and maintainers:

- [`#axon-support:bostoncoop.net`](https://matrix.to/#/#axon-support:bostoncoop.net)

If you are working on Axon itself, the developer room is the place for design and implementation discussion:

- [`#axon-developer:bostoncoop.net`](https://matrix.to/#/#axon-developer:bostoncoop.net)

Any Matrix client can join a room by its address, for example by pasting `#axon-support:bostoncoop.net` into your client's "join room" field.

## GitHub Discussions

For how-to questions, setup help, and ideas, [start a discussion](https://github.com/matrix-axon/matrix-axon/discussions).
Answers there stay searchable for the next person with the same question.

## GitHub Issues

For bugs and feature requests, [open an issue](https://github.com/matrix-axon/matrix-axon/issues/new/choose).
Please check the [existing issues](https://github.com/matrix-axon/matrix-axon/issues) first, and include:

- the Axon version and the client you are using (web, desktop, terminal, or mobile) with its platform and version,
- what you expected to happen and what happened instead,
- steps to reproduce it.

Do not paste access tokens, passwords, or recovery keys into an issue, a discussion, or a chat room.

## Email

If you cannot use Matrix or GitHub, write to [matrix@bostoncoop.net](mailto:matrix@bostoncoop.net).

## Whose server is it?

Axon talks only to the Axon server you configure.
If you are using a server that someone else runs, problems with your account, login, or data on that server are best raised with its operator, because the developers of Axon have no access to it.
